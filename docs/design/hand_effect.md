# 双手 Corner Pin 效果设计

## 目标

视频中的完整链路是：

```text
摄像头帧 → MediaPipe 双手 21 点与手骨架 → 每手拇指/食指/中指/小指
          → 三条相邻四边形 → 不同局部滤镜 → 骨架叠加 → 全屏预览
```

两手对应的拇指、食指、中指和小拇指依次连接，相邻指尖组成三条四边形带。三条带分别使用反色、霓虹和漫画滤镜，只处理原画面对应位置，不把整帧压缩进条带。坐标统一使用左上为原点、范围为 `[0, 1]` 的归一化坐标。

## 模块与接口

| 节点 | 输入 | 输出 | 失败策略 |
|---|---|---|---|
| 摄像头 | 设备编号 | BGR 帧 | 断流：记录错误并退出，避免使用旧帧 |
| 手部追踪 | BGR 帧 | `HandTips` 列表 | 未检测到两只手：返回空结果，进入等待状态 |
| 四角映射 | 两组四指坐标 | 最多三个 `Quad` | 越界：拒绝本帧；单条面积过小：跳过该条 |
| 滤镜合成 | BGR 帧、`Quad` 列表 | 合成帧 | 无有效区域：保留原始帧 |
| 预览 | 合成帧、双手 21 点 | 全屏画面与手骨架 | `Esc`/`q`：正常退出并释放摄像头 |

依赖方向：`app → interface ← core`。应用层只组装追踪器、流水线和渲染器；核心四角映射不 import OpenCV 或 MediaPipe，可独立测试。

## 状态机

```text
WAITING --检测到有效双手四指区域--> TRACKING
TRACKING --少于两手/坐标无效--> WAITING
```

首版不增加丢点保持、插值、手势识别和多滤镜系统。真实画面出现明显抖动时再加 EMA 平滑；误丢点影响体验时再增加短时保持。

## 分阶段开发

1. 已完成：接口、四角映射、状态机、mock 入口和边界自检。
2. 已完成：OpenCV 摄像头与 MediaPipe 双手四指追踪。
3. 已完成：三条相邻区域、反色/霓虹/漫画局部滤镜、透明合成和全屏预览。
4. 下一步：实机视觉校准；只在抖动明显时增加平滑。
