# 双手 Corner Pin 效果设计

## 目标

视频中的完整链路是：

```text
摄像头帧 → MediaPipe 双手关键点 → 每手拇指/食指指尖
          → 四角排序 → 透视变换滤镜 → 与摄像头帧合成 → 实时预览
```

屏幕左侧手的高/低指尖分别作为左上/左下角，右侧手的高/低指尖分别作为右上/右下角。坐标统一使用左上为原点、范围为 `[0, 1]` 的归一化坐标，不让核心逻辑依赖摄像头分辨率。

## 模块与接口

| 节点 | 输入 | 输出 | 失败策略 |
|---|---|---|---|
| 摄像头 | 设备编号 | BGR 帧 | 断流：记录错误并退出，避免使用旧帧 |
| 手部追踪 | BGR 帧 | `HandTips` 列表 | 未检测到两只手：返回空结果，进入等待状态 |
| 四角映射 | 两组拇指/食指坐标 | 顺时针 `Quad` | 越界或面积过小：拒绝本帧覆盖层 |
| 滤镜合成 | BGR 帧、`Quad` | 合成帧 | 变换失败：记录错误并保留原始帧 |
| 预览 | 合成帧 | 窗口画面 | `Esc`/`q`：正常退出并释放摄像头 |

依赖方向：`app → interface ← core`。应用层只组装追踪器、流水线和渲染器；核心四角映射不 import OpenCV 或 MediaPipe，可独立测试。

## 状态机

```text
WAITING --检测到有效双手四点--> TRACKING
TRACKING --少于两手/坐标无效--> WAITING
```

首版不增加丢点保持、插值、手势识别和多滤镜系统。真实画面出现明显抖动时再加 EMA 平滑；误丢点影响体验时再增加短时保持。

## 分阶段开发

1. 已完成：接口、四角映射、状态机、mock 入口和边界自检。
2. 下一步：OpenCV 摄像头与 MediaPipe 双手追踪，实现关键点预览。
3. 然后：透视滤镜、透明遮罩与摄像头合成。
4. 最后：实机校准、抖动平滑、启动与故障验证。
